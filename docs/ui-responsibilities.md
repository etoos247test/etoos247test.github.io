# 메인 UI 책임 분리

메인 화면의 표시 로직은 다음 원칙으로 유지한다.

- `my247.js`: 세션 확인, 로그인/로그아웃 상태, 대시보드 전환
- `index.html`: 로그인 버튼 클릭과 로그인/마스터 패널 열기·닫기
- `public-preview.js`: 공개 공지·시험일정·생활안내·공개 상단 메뉴 구성만 담당하며 로그인/계정 상태를 변경하지 않음
- `home-public.css`: 공개 화면의 표현만 담당하며 일반 로그인 버튼을 숨기지 않음
- `home-shell.js`: 상단 메뉴와 마스터용 화면 보조 기능
- `master-auth.js`: 학생/교사/마스터 인증 요청 처리

일반 로그인 버튼의 표시 여부는 `accountBar`의 로그인 상태에만 연동한다. 공개 미리보기 모드에서는 이 상태를 덮어쓰지 않는다.
