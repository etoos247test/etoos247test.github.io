TEACHER INPUT · STUDENT VIEW

학원 자체 공지방

공지는 1·2관 공통, 수성1관, 수성2관으로 구분합니다. 공통 공지는 한 번만 저장하고 두 관 학생이 함께 열람합니다.
로그인 상태를 확인하는 중입니다.

공지 입력

입력일과 입력자는 저장 시 자동 기록됩니다.

1·2관 공통 공지는 문서와 사진을 한 번만 저장하고 양쪽 학생에게 함께 표시합니다.
입력하면 공지 아래에 ‘관련 페이지 열기’ 버튼이 자동으로 생성됩니다.
JPG·PNG·WebP 사진을 최대 3장까지 선택할 수 있습니다. 사진 한 장당 1MB 이하이며 PDF·한글·워드·엑셀·ZIP 등 일반 파일은 허용하지 않습니다.

시험일정 입력

시험일을 기준으로 날짜순 정리합니다.

화면과 입력 양식은 GitHub Pages에 보관합니다. 공지·시험일정 데이터는 Firestore, 공지 사진 원본은 Firebase Cloud Storage에 저장합니다. 공지당 최대 3장, 사진 한 장당 1MB 이하로 제한합니다. 마스터는 공지 글을 유지한 채 사진만 개별 또는 전체 삭제할 수 있습니다.
