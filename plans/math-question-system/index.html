Firebase 없이 만드는
수학 학생 100명 질문 시스템

학생은 로그인 화면 없이 자신의 번호가 포함된 전용 주소에서 질문하고, 수학 선생님은 M001부터 M100까지 하나의 관리화면에서 확인·답변하는 구조입니다.

현재 · 설계 문서실제 Apps Script 서버 미구축학생 주소 100개 미발급교사 키 미발급
현재 저장 범위이 페이지는 구현 원칙과 작업순서를 정리한 내부 설계안입니다. 학생 질문이 중앙으로 전송되거나 교사가 원격 관리하는 실제 서비스는 아직 가동되지 않습니다.

1. 권장 구조

GitHub Pages는 화면과 짧은 주소를 담당하고, Apps Script는 비밀토큰 검증과 데이터 처리를 담당합니다.

등록 제한과 상태변경
→
자료Sheets + Drive질문·답변·상태 기록
사진 비공개 저장

2. 학생 주소 100개

프로그램 100개를 따로 만들지 않고, 하나의 공통 질문 화면에 학생번호와 예측하기 어려운 토큰을 결합합니다.

학생 1번 https://etoos247test.github.io/m/M001-a7Kp9X2mQ8vL4dTf/ 학생 2번 https://etoos247test.github.io/m/M002-Q4m7Vz91Pc6R2nHd/ ... 학생 100번 https://etoos247test.github.io/m/M100-N5w8Bt42Ks3H7rPc/

학생 화면

  • 학생번호 자동 고정
  • 사진첩 선택·카메라 촬영
  • 질문 내용 입력
  • 접수번호 표시
  • 별도 로그인 없음

주소 보안

  • 번호만 있는 주소 사용 금지
  • 16~24자 무작위 토큰 사용
  • 퇴원·노출 시 토큰 재발급
  • 이전 주소 즉시 정지
  • 토큰 원문은 공개 GitHub에 저장 금지

3. 학생 질문 흐름

01

전용 주소 접속

학생번호와 접근토큰을 주소에서 읽습니다.

02

서버 검증

번호·토큰·활성상태·등록제한을 확인합니다.

03

질문 저장

질문은 Sheets, 사진은 Drive에 저장합니다.

04

접수번호 발급

예: M001-20260803-0004

서버 측 보관

  • HTML·GitHub 코드에 키 원문 금지
  • Script Properties에 해시값 보관
  • 로그인 성공 시 4시간 임시 세션 발급

7. 필수 제한

등록 제한

학생별 1분 1건, 하루 최대 건수, 동일 질문 반복등록 차단을 둡니다.

이미지 제한

사진 수·용량·형식을 제한하고 업로드 전에 자동 축소합니다.

운영 제한

Apps Script 할당량을 고려해 10~20명 시범 운영 후 100명으로 확대합니다.
