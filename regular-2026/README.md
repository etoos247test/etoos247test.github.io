# ETOOS247 대구수성 2026 재수정규 웹 프로그램

- 원본: `재수정규_2026.pptx` 21개 슬라이드
- 실제 사진만 PPT에서 추출해 WebP로 최적화
- 로고, 표, 아이콘, 화면, 흐름도, 가격 카드 등은 HTML/CSS/JavaScript로 재구성
- 외부 라이브러리, 웹폰트, 검색, 분석 스크립트 없음
- `meta robots=noindex` 및 `robots.txt` 포함

## 실행
`index.html`을 열거나 정적 웹 서버/GitHub Pages의 하위 폴더에 그대로 업로드합니다.

## GitHub Pages 권장 경로
`regular-2026/index.html`

## 검색 노출 차단 참고
`meta noindex`는 각 페이지에 적용되어 있습니다. `robots.txt`는 도메인 루트에 있을 때만 표준적으로 적용되므로, 하위 폴더 배포 시 도메인 루트의 robots.txt에도 `Disallow: /regular-2026/`를 추가하는 것이 좋습니다.

## 원문상 불명확한 항목
- 15~19쪽 좌석 가격안은 적용 지점/시점명이 PPT에 기재되지 않아 ‘가격안 1~5’로 보존했습니다.
- 13~14쪽 날짜와 프로그램의 일대일 연결은 원본 배치만으로 일부 확정하기 어려워 각각 보존했습니다.
- 모의고사 그래프와 시간 블록은 구조 설명용 HTML 시각화이며 실제 학생 데이터나 구체 시간표가 아닙니다.
