새교육과정 정시 지원 탐색

기존의 화법과작문·언어와매체, 확률과통계·미적분·기하, 사탐·과탐 개별 선택과목 로직을 제거하고 국어 · 수학 · 통합사회 · 통합과학의 공통 점수 체계로 다시 계산합니다. 첨부 지원참고표는 상담용 시뮬레이션 자료로 사용합니다.

시험자료

첨부한 두 자료를 비교해서 사용할 수 있습니다. 두 자료는 동일한 새교육과정 구조이며 표준점수·등급컷 추정치가 서로 다릅니다.

1. 성적 입력

직접 입력한 값이 최우선입니다. 빈 값은 첨부자료의 원점수·표준점수·백분위 대응곡선에서 자동 보완합니다.

원점수 합-국+수+통사+통과 / 300
표준점수 합-4과목 합산
백분위 비교점수-국+수+(통사+통과)/2
표준점수 상위누적-첨부 상위누적표 기준
백분위 상위누적-첨부 상위누적표 기준
점수를 입력하면 표준점수·백분위·원점수 중 어느 지표에서 상대적으로 유리한지 비교합니다.

2. 지원 가능 대학 검색

대학별 지원참고표의 원점수·표준점수·백분위 기준을 현재 성적과 비교합니다. 선택과목 지원제한·가산점은 새 모델에서 제거했습니다.

검색 결과

성적을 입력하거나 검색 조건을 선택하세요.

새교육과정 모델 반영 내용

프로그램 내부 구조를 단순 표시 변경이 아니라 새 수능 체계에 맞게 다시 구성했습니다.

국어 선택 제거

화법과작문·언어와매체 구분 없이 국어 공통 점수를 사용합니다.

수학 선택 제거

확률과통계·미적분·기하 선택 및 선택과목 가산점 판정을 제거합니다.

탐구 통합

사탐·과탐 개별 2과목 대신 통합사회와 통합과학을 각각 독립 입력합니다.

새 합산식

원점수·표준점수는 4과목 합산, 백분위는 국어+수학+통합탐구 평균으로 비교합니다.

※ 본 탐색기는 첨부된 지원참고표와 점수대응자료를 바탕으로 한 상담용 도구입니다. 2028학년도 실제 대학별 반영비율·영어/한국사 기준·가산점·지원자격은 각 대학의 확정 모집요강을 반드시 다시 확인해야 합니다.
