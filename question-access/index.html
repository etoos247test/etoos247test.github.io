이투스247 질문 시스템 권한센터

한 주소에서 Google 로그인, 교사 등록 요청, 승인 상태 확인, 마스터의 교사 승인·반려를 처리합니다.

로그인하지 않았습니다.

한 페이지 이용 흐름

같은 주소를 교사와 마스터가 함께 사용합니다.

1. Google 로그인교사 또는 마스터가 자신의 Google 계정을 선택합니다.
2. 권한 자동 판정Firestore의 users/{UID} 문서와 교사 등록 요청 상태를 확인합니다.
3. 즉시 처리승인 결과를 화면에 먼저 반영하고 목록 갱신은 뒤에서 처리합니다.

교사 등록 요청

교사 권한이 아직 없습니다. 마스터에게 승인을 요청할 수 있습니다.

교사 권한 확인 완료

현재 계정은 활성 교사입니다. 다음 구축 단계에서 전체 질문 열람·답변 화면으로 연결합니다.

마스터 관리 화면

승인 대기 중인 교사 요청을 처리합니다. 목록 조회가 10초를 넘기면 오류 원인을 바로 표시합니다.

교사 요청만으로 권한이 생기지 않습니다. 마스터 승인 시 users/{교사 UID}에 role: teacher, active: true가 저장됩니다.
