학원 운영 개선
독립 검토 문서

좌석을 제공하는 공간에서 학생의 실행을 지속시키는 관리형 독학학원으로 전환하기 위한 내부 운영안입니다. 현행 수강료 65·75·77만 원과 정원 약 100명을 기준으로 정리합니다.

CORE POSITION

입학은 개방하되, 적합성을 확인하고
입학 후 행동에 따라 관리 강도를 조정합니다.

입학 전 5분 점검은 학생을 선발하거나 등급화하는 도구가 아니라 초기 관리방식을 결정하는 상담자료로 사용합니다.

현재 구조의 강점

  • 기숙형보다 개방적이고 일반 독서실보다 관리가 강함
  • 정해진 좌석과 생활관리로 학습환경을 안정화할 수 있음
  • 주간점검과 월간상담의 기본 틀이 이미 존재함

핵심 문제

  • 관리보다 좌석 상품으로 인식될 가능성
  • 담임 1명당 20~30명은 실행관리까지 하기에는 과중
  • 주간점검이 계획표 확인에 머물면 체감가치가 약함
  • 75만 원과 77만 원의 차이가 분명하지 않을 수 있음

핵심 대상

혼자 공부할 기본 능력은 있으나 계획 유지, 생활리듬, 질문 해결, 학습 조정이 필요한 재수생을 중심으로 합니다.

적합성 재확인이 필요한 경우

휴대전화·교시 규칙을 지속적으로 거부하거나 무단결석이 반복되며 개선 의사가 없는 경우 학생·보호자와 운영방식을 다시 확인합니다.

01

입학 전 5분 점검

학습방식과 운영규칙 수용 가능성을 짧게 확인합니다.

02

입학 후 2주 적응

등원, 계획, 좌석, 휴대전화, 피드백 수용을 실제 행동으로 확인합니다.

03

관리 강도 배정

기본관리·초기집중관리·추가상담으로 구분합니다.

04

정기 피드백

주간 실행점검, 월간 과목상담, 보호자 보고를 연결합니다.

기본관리형

주간계획 점검과 월간 과목상담을 중심으로 운영합니다.

초기집중관리형

첫 2주 동안 계획, 생활리듬, 취약과목을 더 자주 확인합니다.

추가상담형

학생·보호자와 운영규칙, 등록의사, 관리방식을 다시 확인합니다.

분석 표시 원칙간이점검 입력 중에는 점수·영역별 결과·판정·주의영역을 표시하지 않습니다. 모든 응답을 완료한 뒤 결과 출력 또는 인쇄 단계에서만 계산하여 상담자가 확인합니다.
  • 지난주 계획량과 실제 완료량 비교
  • 반복적으로 밀린 과목과 원인 확인
  • 인강 시청과 문제풀이·복습 비율 확인
  • 오답처리와 질문 필요 항목 기록
  • 다음 주 우선순위와 학습량을 담임이 함께 조정
  • 출석률, 과목별 공부시간, 인강 수강량, 교재 진도 확인
  • 모의고사 변화와 반복적으로 밀리는 과목 분석
  • 가장 중요한 과목, 줄여야 할 공부, 반드시 실행할 과제 확정
  • 수학 질문 가능 시간 명시
  • 즉시 답변이 어려운 문제의 처리시간 안내
  • 국어 지문·탐구 학습순서·인강과 교재 선택 지원
  • 출석률과 지각, 계획 실행 수준, 과목 진행상황
  • 생활관리 상태와 상담자가 조정한 내용
  • 다음 달 핵심관리 항목
  • 학생의 민감한 상담내용은 제외하고 필요한 범위만 공유
65만 원현행 수강료 1단계

기본 좌석과 기본 관리서비스의 포함범위를 명확히 설명합니다.

기본 범위 표준화
75만 원현행 수강료 2단계

좌석 차이뿐 아니라 추가 편의와 관리서비스를 구체적으로 표시합니다.

10만 원 차이 설명
77만 원현행 수강료 3단계

75만 원과의 2만 원 차이를 학생과 보호자가 즉시 이해할 수 있어야 합니다.

2만 원 차이 명확화

정원 운영

  • 1단계: 75~80명에서 관리체계 정착
  • 2단계: 85~90명에서 관리품질 재확인
  • 3단계: 관리품질이 유지될 때 최대 100명

가격 개선의 우선순위

가격을 먼저 바꾸기보다 좌석, 공간, 관리, 상담, 질문지원의 차이를 표준화하는 것이 우선입니다. 관리서비스가 같다면 좌석 추가금임을 분명히 표시합니다.

즉시 시행

학원 정체성·목표 학생 정의, 5분 간이점검, 2주 적응관리, 주간 실행점검, 상담기록 저장
