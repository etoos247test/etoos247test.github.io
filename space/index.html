공간·좌석 운영
검토 화면

좌석 이름을 판매하는 데 그치지 않고, 각 공간이 어떤 학습 행동을 지원하는지와 수강료 차이를 명확하게 설명하기 위한 내부 기준입니다.

! 외부 시설 홍보용이 아니라 좌석·공간 운영체계를 정리하는 내부 문서입니다.

공간은 서로 다른 학습 문제를 해결해야 합니다.

솔리터리룸

시선 분산을 줄이고 장시간 자기주도학습에 집중하는 공간입니다.

  • 개인 몰입
  • 고정좌석
  • 교시형 운영

리프레시룸

학습 리듬을 무너뜨리지 않는 짧은 휴식과 컨디션 조절 공간입니다.

  • 짧은 회복
  • 대화 범위 제한
  • 체류시간 기준

스탠딩존

졸음과 자세 정체를 해소하며 짧게 집중을 전환하는 공간입니다.

  • 서서 학습
  • 장기 점유 제한
  • 교시 중 조용한 이용

렉처룸

필요한 강의와 설명을 선택적으로 활용하는 보완 학습 공간입니다.

  • 소규모 수업
  • 특강
  • 모의고사

코칭룸

담임·과목상담·보호자 상담을 외부 방해 없이 진행합니다.

  • 1:1 상담
  • 학습계획 조정
  • 민감정보 보호

질문지원 공간

수학과목을 중심으로 질문 접수와 설명이 가능한 시간을 분리합니다.

  • 질문 대기
  • 풀이 설명
  • 처리시간 안내

현행 수강료와 좌석 설명

현행 월 수강료는 65만 원, 75만 원, 77만 원입니다. 가격을 바꾸기 전에 각 단계의 차이를 한 문장으로 설명할 수 있어야 합니다.

65만 원기본 단계

기본 좌석, 공통 출결·생활관리, 주간점검, 월간상담의 포함범위를 명확히 표시합니다.

75만 원상위 단계

기본형보다 달라지는 좌석 구조, 위치, 편의, 이용조건을 10만 원 차이만큼 구체적으로 설명합니다.

77만 원최상위 단계

75만 원과의 2만 원 차이가 좌석인지 서비스인지 즉시 알 수 있도록 별도 항목으로 표시합니다.

권고관리서비스가 세 단계 모두 동일하다면 수강료 차이는 ‘관리등급’이 아니라 ‘좌석·공간 추가금’으로 표현하는 편이 정확합니다.

좌석 운영 판단 기준

집중 차단 정도칸막이·독립성·주변 시선
이동 편의질문·상담·화장실·출입 동선
소음 민감도출입구·복도·공용공간과 거리
장기 이용 적합성책상 크기·수납·조명·환기
추가 서비스관리빈도와 혼동되지 않게 별도 표시

정원 확대 전 확인

01

75~80명

관리체계와 공간 동선을 먼저 안정화합니다.

02

85~90명

소음·질문대기·담임업무량을 다시 측정합니다.

03

최대 100명

관리품질과 공간 이용이 유지될 때만 확대합니다.

04

재조정

중도이탈과 불편신고가 늘면 정원보다 품질을 우선합니다.

운영 개선 전체 보기업무 포털로 돌아가기

좌석명과 실제 제공내용이 일치하는지 현장 확인 후 최종 문구를 확정해야 합니다.
